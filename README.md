# bowman-ui

Presentational React components for AI chat interfaces, extracted from an internal application.

`@re-cinq/bowman-ui` provides props-driven chat UI building blocks — message rendering, composer, conversation list, app shell — with no authentication, data-fetching, routing, or i18n dependencies. Consumers supply data and labels; the components render them.

Status: repository bootstrap. The package skeleton, build contract, and components land through the E3 epic issues.

Naming: HAL is the engine, Bowman is the face.
